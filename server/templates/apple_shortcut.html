Sync notes and tasks to iPhone

Apple only imports signed shortcuts, which this server can't produce, so you build this short one once in the Shortcuts app. The server remembers what it has already sent, so the shortcut needs no duplicate checks: each run returns only new notes and open tasks.

Values to use

URL:

{{ pending_url }}

Header X-Upload-Token:

{% if token %}
{{ token }}

This read-only token can't change notes or tasks. Anyone with the shortcut can read your notes; revoke it by changing TODOS_READ_TOKEN in the server .env.

{% else %}

TODOS_READ_TOKEN is not set in the server .env. Set it and redeploy, then reload this page.

{% endif %}

Build the shortcut (iPhone Shortcuts app → +)

  1. Get Contents of URL: paste the URL, expand Show More, set Method GET, and add header X-Upload-Token with the token above.
  2. Get Dictionary from Input (input: Contents of URL). Name this result by long-pressing it if needed; the next steps all read from it.
  3. Get Dictionary Value: key notes, then Repeat with Each on the result. Inside: Get Dictionary Value key text from Repeat Item, then Create Note with that value.
  4. Add another Get Dictionary Value (key todos, from the dictionary in step 2), then Repeat with Each. Inside: Get Dictionary Value key text from Repeat Item, then Add New Reminder with that value as the title.
  5. Add a third Get Dictionary Value (key dated_todos), then Repeat with Each. Inside: Get Dictionary Value key text and another with key due_utc from Repeat Item; run Get Dates from Input on the due_utc value; then Add New Reminder with the text as title and that date as the Due Date.

Use it

Run it once and allow Notes and Reminders access. For automatic syncing, add a personal Time of Day automation that runs the shortcut.

One-way import: edits or completion in Apple apps don't come back. Add ?peek=1 to the URL to test without marking items as sent, or ?reset=1 once to resend everything (delete already-imported items first, or they'll be duplicated).
